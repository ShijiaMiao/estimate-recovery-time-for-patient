# Local data folders

Create the following directories after obtaining the source data:

```text
data/raw/mauvieux_2025/
data/raw/tiles_2018/
```

Keep the downloaded files unchanged inside those folders. Raw and processed
participant data are excluded from Git by `.gitignore`. Only code, schemas,
small synthetic examples, and non-disclosive derived results should be shared.

See [`../docs/DATA_DOWNLOAD_CN.md`](../docs/DATA_DOWNLOAD_CN.md).
