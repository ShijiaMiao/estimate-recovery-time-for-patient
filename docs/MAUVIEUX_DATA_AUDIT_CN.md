# Mauvieux 2025开放数据审计

## 下载内容

压缩包包含6个Excel工作簿，没有单独的README文件：

1. 活动—休息节律拟合曲线；
2. 口腔温度拟合曲线；
3. 握力拟合曲线；
4. 各生理功能的周期与振幅表；
5. 研究1睡眠质量表；
6. 研究2训练前后睡眠质量表。

没有发现隐藏工作表或隐藏数据列。图形工作簿中的长时间序列主要由Excel
公式生成，是组水平的拟合曲线，不是参与者的原始手环记录。

## 三个阶段的确切含义

- ZT1：周末恢复，周五中午至周日夜间；
- ZT2：夜班工作的最初72小时，周日夜间至周三中午；
- ZT3：后半周夜班，周三中午至周五早晨。

工作模式是固定夜班，通常为周日夜间开始，连续工作至周五早晨。数据没有
提供每个参与者每天的日期或每日班次行。

## 参与者级数据

研究1睡眠表包含24人：

- 12名身体活动组；
- 12名久坐组；
- 每人有ZT1、ZT2、ZT3三个阶段；
- 指标为卧床时间、总睡眠时间、入睡潜伏期、入睡后清醒时间和睡眠效率。

研究2睡眠表包含16人：

- 同一参与者有运动训练前和训练后数据；
- 每次均有ZT1、ZT2、ZT3三个阶段；
- 指标与研究1相同。

周期与振幅工作簿还保留了24名参与者在以下功能上的派生节律参数：活动、
口腔温度、优势手握力、非优势手握力、平均动脉压、无氧功率、呼气峰流量
和Stroop任务。但这些是每个阶段拟合后的周期/振幅，不是逐日原始读数。

## 对ShiftRecoverPy的意义

这套开放数据可以完成：

- 公开数据读取与清理；
- ZT1、ZT2、ZT3阶段比较；
- 活动组和久坐组比较；
- 训练前后配对比较；
- 睡眠与多个生理节律的多模态展示。

它不能可靠完成：

- 计算夜班结束后第1、2、3天分别偏离基线多少；
- 判断某个人到底在第几天恢复；
- 比较1个、2个、3个连续夜班后的恢复时间；
- 建立包含6至8个独立稳定休息日的个人基线。

原因是ZT1把整个恢复周末合并成一个阶段，缺少恢复日1和恢复日2的独立
记录。ZT1也不等于已经恢复的正常基线；较长睡眠可能表示补偿性睡眠。

## 项目决策

保留Mauvieux数据作为“完全开放、任何人都能复现”的阶段比较案例，但不
用它声称估计了逐日恢复时间。核心恢复时间算法继续用模拟数据验证，真实
逐日主分析等待TILES-2018获批后完成。

项目现已提供`mauvieux`命令，将两张参与者级睡眠表转换成长格式CSV，并
生成按研究、组别、训练状态和阶段分层的描述性统计。
